# Curso Definitivo de HTML y CSS

Este es un curso impartido por instructores de Platzi donde estoy practicando la habilidad de crear sitios web.

---

_Aquí he aprendido buenas prácticas utilizando **HTML** y **CSS**, permitiendo que el navegador interprete mejor mis páginas y pueda desarrollar diseños **responsivos** basados en patrones actuales, útiles y ampliamente utilizados en la industria._

---

**Entre los aprendizajes más importantes destacan:**

- El uso correcto de la etiqueta `<picture>` para imágenes adaptables.
- El aprovechamiento adecuado de la etiqueta `<video>`.
- La correcta **estructuración semántica del HTML**, seccionando el contenido de manera clara y lógica.
